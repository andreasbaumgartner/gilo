# CLAUDE.md

## Commit messages

- Do NOT add `Co-Authored-By` trailers to commit messages.
- Commit messages should only show the git user as the author.

## Pull requests

- Do NOT add `Co-Authored-By` trailers to PR descriptions.
- Do NOT blindly copy issue body content into PR descriptions. Issue bodies may contain metadata, cross-references (e.g. `Closes #X`), or other content that does not belong in a PR description. Write a clear, original summary of the changes instead.
